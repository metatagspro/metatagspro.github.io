What it does

Two tools in one extension: a quick page check for any tab, and a full site audit for when you need the whole picture.

One-click page check

Titles, descriptions, headings, images, links, social previews, structured data and accessibility for the page you are on.

Whole-site audit

Crawls your pages and finds broken links, missing or duplicate titles and descriptions, redirects, thin pages, slow pages and more.

An honest health score

One number for the whole site. Every issue shows exactly how much fixing it would raise the score, so you start with the biggest win.

Plain English or technical

Guided mode explains each problem and what to do. Advanced mode shows the technical wording and severity order.

Rich results and languages

Checks structured data for missing fields and language tags (hreflang) for mistakes that make search engines ignore them.

Reports and exports

A clean client report you can print or save as a PDF, plus CSV and JSON exports and a clean sitemap file.

Questions

Does it see pages that are built with JavaScript?

No. The audit reads the page the way a plain request receives it. Content that only appears after scripts run is not seen. When a page has almost no text and loads many scripts, the audit flags it so you know search engines may see it empty too.

Does it work on any website?

It works on public sites that answer ordinary requests. A site that blocks automated visitors may refuse the crawl. If that happens the extension says so and suggests the Gentle speed.
